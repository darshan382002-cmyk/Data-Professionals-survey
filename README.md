
# 📊 Data Professionals Survey Power BI Project

This repository contains an **interactive Power BI report** focused on Data Professionals Survey analysis and cohort insights.

## 📝 Report Tabs

### 1️⃣ Data Professionals Survey
Includes key performance indicators (KPIs) such as:
- 🆕 New Data Professionals Survey Participants
- 🔄 Returning Data Professionals Survey Participants
- 🔝 Top N Data Professionals
- 🔻 Bottom N Data Professionals
- 📊 Key Survey Metrics and Insights

### 2️⃣ Cohort Data Professionals Survey
- 📈 Visual cohort diagram to analyze Data Professionals Survey cohort patterns and trends.

## 📌 Purpose
This report helps explore survey data, identify key patterns, and present insights through interactive visualizations to support data-driven decision-making.

---

🔗 Feel free to explore the `.pbix` file and interact with both dashboard tabs.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
